## Overview

In order to promote future community development and construction, we cooperated with Ningbo Fuming Street to build a building intelligent emergency simulation system. Using discrete simulation technology, we build simulation models based on real Fuming Street residential and commercial buildings, and import virtual personnel to simulate the evacuation of people when dangerous accidents such as fire occur.

![Building Emergency Simulation](assets/74.png)
![Building Emergency Simulation](assets/75.png)

## Features

- **Community Modeling**: Building simulation models, scientific evaluation of activities arrangement.
- **Solution Evaluation**: Feasibility of the escape time on each floor, rationality of the staffing arrangement.
- **Scene Reproduction**: Panoramic camera builds 720-degree surveillance.
- **Emergency Training**: 3D guidance for the shortest escape route recommended in different areas.
