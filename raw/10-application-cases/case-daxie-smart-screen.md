## 项目概述

应宁波大榭码头有限公司要求，开发一套基于智能仿真技术的智慧大屏解决方案。打破数据隔阂，为码头生产作业透明化提供保障，提高码头软实力。

> At the request of Ningbo Daxie Merchants International Terminal Co., Ltd., we developed a set of intelligent large-screen solution based on intelligent simulation technology, breaking the data barrier, providing guarantee for the transparency of dock production operation, and improving the soft power of the dock.

## 智慧大屏特点 Smart Screen Features

- 作业可视化、效率可视化、状态可视化 / Job visualization, efficiency visualization, state visualization
- 数据回放，深入研究复现作业问题 / Data playback, in-depth study of the problem of reproduction operation
- 实时仿真预测，超前洞察效率瓶颈 / Real-time simulation, predict efficiency bottlenecks
- 端到端传输，足不出户即总览大局 / End-to-end transmission, you can see the big picture without leaving home
- 深度嵌入安全保障系统，实时监测生产安全 / Deeply embedded safety guarantee system, real-time monitoring of production safety
